# Marketing screenshots

Five owner-supplied game captures, preserved as `1.png` through `5.png`, with matching JPG copies for marketing uploads. Capture build/date were not supplied.

Conversion: macOS `sips -s format jpeg -s formatOptions 95 INPUT.png --out OUTPUT.jpg`. JPG dimensions match each original PNG. Original PNG bytes were not modified; no compositing, cropping or retouching. JPEG encoding is lossy.

[manifest.json](manifest.json) records dimensions, file sizes and SHA-256 hashes for both formats. These files are preparation assets, not build inputs. See [CREDITS.md](../../../CREDITS.md) for project artwork and third-party notices. Keep original captures when making future resized/compressed derivatives.
